# 機密等級 (Security Level) 功能設計規格

## 1. 簡介
為文件管理系統新增「機密等級」欄位，以記錄文件的機敏程度。此欄位將與原有的「文件類別」共存。同時，在「匯出文件一覽表 (Word)」時，提供對應的佔位符供範本替換。

## 2. 資料模型變更 (Google Sheets)
- **欄位擴充**：於 `env.js` 中的 `DOC_COL` 增加 `SECURITY_LEVEL` 欄位（對應工作表的第 Q 欄，索引為 16）。
- **選項常數**：新增 `SECURITY_LEVELS = ['一般', '限閱', '密', '機密']`。
- **資料遷移 (`migrateV8`)**：
  - 在 `deploy.js` 撰寫遷移指令，替既有的「文件清單」表頭補上「機密等級」。
  - 針對現有資料列，若此欄位空白，則自動填入預設值「一般」。
  - 套用資料驗證（下拉選單）至該欄位。

## 3. 後端邏輯 (`code.js`)
- **初始化資料 (`apiGetInitData`)**：將 `SECURITY_LEVELS` 清單回傳給前端。
- **文件儲存 (`apiCreateDoc`, `apiUpdateDoc`)**：確保寫入與更新資料陣列時，包含使用者選擇的機密等級。

## 4. 前端介面 (`index.html`)
- **文件表單 (`docModal`)**：在新增/編輯彈窗內，新增「機密等級」的必填下拉選單。
- **清單與詳細面板**：
  - 列表區：考量欄位寬度，於 `docTable` 新增「機密等級」欄位。
  - 詳細面板 (`detailPanel`)：在右側詳細資訊區塊內顯示機密等級。
- **匯出文件一覽表 (Word)**：
  - 修改 `execDocxExport` 邏輯：在組裝給 docxtemplater 的資料物件時，加入 `security_level` 屬性。
  - 使用者後續可於 Word 範本中使用 `{security_level}` 取代原本的 `{category}`。

## 5. 實作範圍與限制
- 本次改動不涉及改變「權限檢核邏輯」。「機密等級」目前僅作為展示與紀錄用途，暫不影響存取權限。
- 遷移函數 `migrateV8()` 為冪等設計，可重複執行而不會損壞資料。
